# V1

## /game/credit pays a voided game's share, it is not a stake
The game server (gameapis mpesa_multi_share.php) calls POST /game/credit once per remaining player when a dropped player voids a 3/4 player game, sending that player's share (floor(pot*0.95/remaining)). It pays from game wallet escrow (payout|dropped, escrow_release reason game_drop_share), closes the game, and sweeps the leftover (< one share) to the house as house_cut source game_drop_payout. Stakes go through POST /game/bets. Until Oct 2026 /game/credit wrongly debited players as a stake with a 5% game_credit house cut; those historical ledger entries remain and finance code must keep handling them (tests use legacyGameCreditStake()).
